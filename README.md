
# 🌍 Air Quality Anomaly Radar — Tamil Nadu

An interactive Power BI Dashboard designed to track and detect Air Quality Index (AQI) anomalies over time across key cities in Tamil Nadu (Chennai, Madurai, Coimbatore, Salem, Trichy).

## 📊 Dashboard Preview
![Dashboard Preview](DASHBOARD%20PNG.png)

## 🚀 Key Features
- **Spatial Map Radar:** Real-time city-level spatial mapping of AQI values across Tamil Nadu.
- **Pollutant Breakdown:** Multi-metric analysis of PM2.5, PM10, NO2, and SO2 spikes causing anomalies.
- **Temporal Analysis:** Time-series tracking with interactive Date Range slicer.
- **Executive KPIs:** Live metrics for Average AQI, Average PM2.5 levels, and Maximum NO2 spikes.

## 🛠️ Tech Stack
- **Tool:** Microsoft Power BI Desktop
- **Analytics:** Data Modeling, Aggregations & DAX
- **Domain:** Environmental Data Analytics / Air Quality Monitoring
